# ELEGANCE - WORKOUT ROUTINE

Static GitHub Pages workout tracker for `sirenistic`.

## Files

- `elegance.html` — named application file.
- `index.html` — identical copy for GitHub Pages root deployment.

## GitHub Pages

1. Create a repository under `sirenistic`.
2. Add `index.html` (and optionally `elegance.html` and this README).
3. Open repository Settings → Pages.
4. Set Source to `Deploy from a branch`.
5. Select the branch containing `index.html` and `/ (root)`.
6. Save. GitHub Pages will publish the site.

The app stores workout logs and progression settings in the browser's `localStorage`. Data is local to the browser/device and is not committed to GitHub.
